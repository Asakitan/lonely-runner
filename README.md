# 孤独跑者：六个整数速度的紧例

一个静止观察者和六名跑者从单位圆上的同一点出发。记 $D$ 为所有时刻中，观察者到最近跑者的圆周距离所能达到的最大值。

对六个互异正整数速度，除以最大公因数并排序：**如果第四个速度不超过 12，$D=1/7$ 当且仅当归一化速度为 $(1,2,3,4,5,6)$**；其余组合的 $D$ 严格大于 $1/7$。

第五、第六个速度不设上限。证明先用区间引理排除无限多个组合，再用有理数精确检查剩余 529 个六元组。第四速度超过 12 的完整分类不在本结果范围内。

## 复核

在项目根目录运行（Python 3.9+，仅需标准库）：

~~~bash
python -B verify_lonely_runner.py
~~~

输出应显示 529 个待检六元组；未找到严格好时刻的只有 $(1,2,3,4,5,6)$ 及其 2 倍和 3 倍。三组归一化后是同一个紧例。
